# 3. Collaboration Workflow & Decision Matrix

The manual defines an explicit multi-stage AI collaboration workflow:

$$\text{User} \rightarrow \text{ChatGPT (Planning)} \rightarrow \text{Antigravity (Implementation)} \rightarrow \text{AI Studio/Stitch (UI)} \rightarrow \text{Ollama (Debugging)} \rightarrow \text{ChatGPT (Review)} \rightarrow \text{Health Script} \rightarrow \text{Build Script} \rightarrow \text{Release Script} \rightarrow \text{GitHub}$$

### Decision Authority Matrix
- **Architecture Decisions**: **ONLY ChatGPT**
- **Implementation Decisions**: **Antigravity**
- **UI & Aesthetic Decisions**: **AI Studio + Stitch**
- **Local Debugging & Fixes**: **Ollama**
- **Release Approval**: **ONLY ChatGPT**
