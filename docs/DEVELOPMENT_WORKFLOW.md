## Overview

This document outlines the development workflow for VNEXIFY Creator OS, including environment setup, coding practices, and documentation expectations.

## Onboarding

- Clone the repository
- Review documentation in `docs/`
- Install frontend, Electron, and backend dependencies once approved
- Configure local environment using `.env.example`

## Development Process

- Work in feature branches for new work
- Keep changes scoped to the current phase and approved tasks
- Use documentation as a reference for project guidelines

## Documentation Process

- Add documentation updates alongside scaffold and workflow changes
- Maintain cross-references in related docs
- Log major decisions in [DECISIONS.md](DECISIONS.md)
