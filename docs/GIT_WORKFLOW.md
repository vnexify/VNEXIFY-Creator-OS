## Overview

This document describes the Git workflow for VNEXIFY Creator OS, including branching, commits, and review practices.

## Branch Strategy

- `main` for stable project baseline
- `phase/*` for development phase work
- `docs/*` for documentation changes

## Commit Guidelines

- Use concise commit messages
- Reference related tasks or decisions when relevant
- Avoid mixed unrelated changes in a single commit

## Pull Request Process

- Create PRs for changes to code or documentation
- Include a summary of work and any verification steps
- Request review from at least one collaborator

## Versioning

- Use semantic versioning for formal releases
- Capture project iteration in `CHANGELOG.md`
