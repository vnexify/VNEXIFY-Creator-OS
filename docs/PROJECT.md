## Project Purpose

VNEXIFY Creator OS is a desktop application scaffold built to combine a React + TypeScript frontend, an Electron shell, and a Python FastAPI backend. The purpose of this document is to provide high-level project context and direction.

## Scope

- Frontend scaffold using React, TypeScript, and Vite
- Electron desktop bootstrap and runtime
- Backend scaffold using Python FastAPI with SQLite support
- Core workspace structure, docs, assets, and tooling templates
